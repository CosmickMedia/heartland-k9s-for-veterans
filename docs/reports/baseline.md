## Interaction checklist (observed)

- Client-side routing (wouter): all internal links are <a href> with onClick preventDefault + pushState; layout useEffect calls window.scrollTo(0,0) on every location change (verified: scrollY reset to 0 after navigating /contact -> /stories from scrollY 800). External Donate links open https://heartlandk9s.org/ in a new tab (target=_blank rel=noopener noreferrer).
- Mobile menu (<1024px): hamburger button toggles React boolean; icon swaps lucide-menu <-> lucide-x; dropdown panel absolutely positioned below the 80px bar, animated with animate-in slide-in-from-top-2 (0.15s 'enter' keyframe from translateY(-8px)); closes when a menu link is clicked (onClick -> setOpen(false)) or hamburger re-clicked; NO backdrop, NO body scroll lock (body overflow stays 'visible'), NO Escape/outside-click handling, NO focus trap; active route link gets bg-muted + text-secondary. Verified in headless Chrome at 390px.
- Desktop nav link hover: color foreground@80% -> secondary rgb(184,46,69) via transition-colors 150ms; active route link is permanently text-secondary (measured on /about).
- Logo link hover: <img> scales to 1.05 (group-hover:scale-105, transition-transform 300ms).
- Buttons hover: background alpha only — bg-secondary -> secondary/90, bg-primary -> primary/90, outline white/10 -> white/20, ghost transparent -> secondary/10; footer links white/80 -> white. 'hover-elevate' / 'active-elevate-2' classes are present in markup but have no CSS rules (no effect). Focus-visible ring 1px --ring navy; disabled opacity 50%.
- Feature cards (.card-hover-effect): on hover (only when @media(hover:hover)) translate 0 -4px and shadow-sm -> shadow-lg, transition all 300ms; the inner 'Learn more' link widens its icon gap 4px -> 8px (hover:gap-2 transition-all). Other 'bg-card … hover:-translate-y-1 transition-transform duration-300' cards on program/get-involved pages lift 4px with no shadow change.
- Hero entrance animation (home only): badge, h1, p, and CTA row use tailwindcss-animate 'animate-in slide-in-from-bottom-4/6 duration-700 [delay-150|300|500] fill-mode-both' -> each fades/slides up 16-24px over 0.7s, staggered 0 / .15 / .3 / .5s on mount. No scroll-triggered animations, no IntersectionObserver, no parallax.
- Contact form: all five fields have the HTML required attribute (native browser validation bubbles; form.noValidate=false, checkValidity()=false when empty, email uses type=email). onSubmit: e.preventDefault(); setSending(true) -> button text 'Sending...' + disabled for 1000ms via setTimeout -> toast {title:'Message Sent', description:'Thank you for reaching out. We will get back to you shortly.'} and form.reset(). NOTHING is transmitted (no fetch/XHR, no action endpoint, fields have no name attributes). Verified from bundle source; form was not submitted during measurement.
- Accordion / FAQ: none. The CSS contains radix accordion keyframes (accordion-down/up) from the shadcn preset but no Accordion component exists in the JS bundle and no data-state accordion markup renders on any route.
- Sticky header: position sticky top 0 with backdrop blur; no scroll-based shrink, shadow, or class toggling.
- Toast viewport (radix) is mounted globally; toasts appear top full-width on phones, bottom-right (max 420px) from 640/768px.
- No dark-mode toggle, no carousel/slider, no modal/dialog usage, no video, no lazy-loaded images (all images are CSS background-image or a plain <img> logo).
