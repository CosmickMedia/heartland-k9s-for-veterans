# payload-src — source of truth for the import payload

`tools/build-payload.mjs` merges every `records/**/*.json` file (each file = one manifest record object or an array of them, exactly in the `hk9-payload/1` record shapes from `docs/ARCHITECTURE.md` §8), copies `content/*.html`, and joins `payload/media-index.json` (written by `tools/fetch-media.mjs`) into `payload/manifest.json`. It validates every `{{token}}` against known keys and fails the build on dangling references.

Layout:
- `records/pages/*.json` — Pages (reference pages `ref:page:*`, migrated live pages `live:page:*`, new pages `new:page:*`), including `meta.hk9_sec_*` section values and `template`.
- `records/stories|teams|people|partners|campaigns|events/*.json` — CPT records.
- `records/barkode/*.json` — registry records (**generated by `tools/extract-registry.mjs`, gitignored**; contains personal contact data).
- `records/terms.json`, `records/menus.json`, `records/settings.json`, `records/reading.json`, `records/redirects.json`.
- `content/<key-with-colons-replaced-by-__>.html` — block markup with tokens.
- `source/` (gitignored) — original Fusion HTML captured for traceability.
